## Interactive show (no flash)

```text
chart.show();        // block until you close the window  ← default
chart.show(true);    // same
chart.show(false);   // non-blocking; window stays open (strong ref)
Matplotlib.show();   // last chart, blocking
Matplotlib.close();  // dispose leftover non-modal windows
```

Do **not** pass `-Djava.awt.headless=true` if you want a real GUI.
Headless mode writes a temp PNG and prints its path instead.
